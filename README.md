# 瑞翔社區日間作業所 116年度三大領域學習成效與檢核評量系統

本專案依據《116年度身心障礙者服務執行計畫暨評量手冊》標準開發，包含三大核心領域之完整評量追蹤系統：

1. 🏥 **健康衛教評量系統** (`index.html`)：生活衛生、健康飲食、緊急應變、身體自主。
2. 🎓 **終身學習檢核系統** (`lifelong.html`)：生活常規、用電安全、防災應變、食品安全消費。
3. 🌸 **性別平等教育系統** (`gender.html`)：身體界線、人際社交、性別平權與分工、親密關係與倡議。

三大系統皆提供**學員姓名管理**、**三階段評量（前測／課堂月檢核／後測）**、**0～5分提示等級打分**、**學習自立階段自動判定**、**週期平均值與進步率分析**、**視覺化圖表**、**ISP 個別化質性評語自動生成**，並附帶 **Excel/CSV 匯出** 與 **A4 專業列印排版**。

---

## 🌟 核心功能

1. **三階段評量記錄**：
   - **第 1 個月：前測基準**（建立真實起點能力）
   - **第 2 個月：課堂平時／月檢核**（實作操作與提示引導）
   - **第 3 個月：後測驗收**（綜合情境驗收成效）
2. **0～5 分提示等級標準**：
   - `5分`：可獨立完成（🟢 獨立自主階段 4.5~5.0分）
   - `4分`：口語提示（🔵 口語提示階段 3.5~4.4分，基本自立達標）
   - `3分`：肢體協助（🟡 肢體協助階段 2.5~3.4分）
   - `2分`：部分協助（🟡 部分協助階段 2.0~2.4分）
   - `1分`：大量協助（🟠 大量協助階段 1.0~1.9分）
   - `0分`：無法完成（🔴 引導探索階段 0.0~0.9分）
3. **週期平均與進步指標公式**：
   - 指標平均分（0~5分）
   - 進步分數 ＝ 後測得分 － 前測得分
   - 達成率（%） ＝ (實際得分 ÷ 滿分) × 100%
   - 進步率（%） ＝ (進步分數 ÷ 前測得分) × 100%
   - 成長百分點 ＝ 後測達成率 － 前測達成率
4. **全自訂文字與標題編輯器**：
   - 可隨時線上修改系統主標題、機構名稱、四季主題、每一題指標內容、學員姓名與備註。
5. **專業列印系統 (A4 / PDF)**：
   - 支援列印「個人評量打分表（含0~5分方塊與色彩）」、「全班分析總表」、「四大圖表」、「ISP成果冊」與「空白手寫評量用紙」，內建簽核欄。

## 🚀 如何使用

### 1. 直接開啟網頁
- 雙擊 `index.html` 進入【健康衛教評量系統】
- 雙擊 `lifelong.html` 進入【終身學習檢核系統】
- 雙擊 `gender.html` 進入【性別平等教育評量系統】
（在任何頁面上方皆可一鍵切換不同系統）

### 2. 免費部署到 GitHub Pages (線上網站)
1. 將專案上傳至 GitHub 儲存庫。
2. 點擊儲存庫的 **Settings** ➔ **Pages**。
3. 在 **Branch** 選擇 `main` 分支並按 **Save**。
4. 即可獲得專屬的免費線上評量系統網址，手機、平板與電腦皆可連線打分！
